## Definition of done

Work in this repo counts as done only when ALL of these hold:

1. `bash .github/scripts/detect-and-test.sh` exits 0 (gate is green).
2. Behavior changes are covered by new or updated tests.
3. No dependency, artifact, cache, or secret was committed.
